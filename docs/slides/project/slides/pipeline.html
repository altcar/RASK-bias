RASK-bias · UoB Datathon · 1 / 2

Five steps. We scanned 2,484 Kaggle resumes and matched them to 120 US LinkedIn postings. A pretrained MiniLM sentence encoder scores how well a CV matches a job. We audited it with counterfactual twins: the same CV with only gender, city or degree changed. Location changed 15% of decisions, so we added a LEACE eraser, a closed-form linear layer, and shipped both versions in one ONNX model behind a Streamlit app.
